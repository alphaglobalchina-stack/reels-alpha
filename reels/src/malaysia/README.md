# ريلز ماليزيا — سقطري للسياحة والسفر | Socotra Travel & Tours

ريلز موشن جرافيك 9:16 (1080×1920، 30fps، 18 ثانية = 540 إطاراً بالضبط) بتصميم Bento Grid ولقطة واحدة متصلة.

## المخرجات (`out/malaysia/`)
| الملف | الوصف |
|---|---|
| `reel_malaysia.mp4` | H.264 + AAC، 540 إطاراً، ~15.6MB |
| `thumbnail.jpg` | لقطة العنوان (الإطار 75) |
| `test_first3s.mp4` | تصدير الاختبار الأول (0–3ث) |
| `qa/f*.jpg` | لقطات الفحص: كل ثانيتين تقريباً + لحظات مهمة |

## التشغيل
```bash
cd reels
npm install
npm run render:malaysia     # → out/malaysia/reel_malaysia.mp4
npm run still:malaysia      # → out/malaysia/thumbnail.jpg
npx remotion studio         # معاينة (Composition: MalaysiaReel)
# إعادة توليد الأصول (اختياري):
python3 ../scripts/prep_malaysia.py         # تدرّج الصور + قص الشعار   (numpy pillow)
python3 ../scripts/cutout_towers.py         # قصّ الأبراج                (rembg[cpu] scipy)
node ../scripts/make-malaysia-audio.mjs     # الموسيقى والمؤثرات
```

## هيكل الكود (`reels/src/malaysia/`)
- `data.ts`: **كل النصوص والأرقام وأسماء الصور ومواقع البطاقات والتوقيتات ومحطات الكاميرا** في ملف واحد.
- `camera.ts`: كاميرا بمحطات ومنحنيات easing سينمائية (سريعة بين المحطات وبطيئة عند الوصول)، وقوس جانبي و"تنفّس" في الزوم أثناء الانتقال. الميل الثلاثي الأبعاد (pitch/yaw) مشتق من سرعة الكاميرا، والدوران (roll) من المحطات. فيها أيضاً عمق الميدان المحاكى.
- `sections.tsx`: البطاقات (العنوان والأبراج، المدة، النوع، المدن، المميزات، السعر، احجز الآن، التواصل، الشركة).
- `board.tsx`: الأعمدة الجانبية الزخرفية، والعناصر الطافية، والطائرة، وطبقتا الخلفية والمقدمة (parallax).
- `icons.tsx`: أيقونات SVG بأسلوب 3D ناعم مرسومة بالكود.
- `ui.tsx`: البطاقة، النص العربي RTL، عدّاد البكرات (slot)، شريحة الأيقونة ثلاثية الأبعاد.
- `sound.tsx`: الموسيقى ومواضع المؤثرات (محسوبة من التوقيتات والعدّادات).

| 2.webp | صورة واقعية: جسر لنكاوي المعلّق | `langkawi-skybridge.jpg` | بطاقة لنكاوي |

- مجلدا `assets/photos16` و`photos17` يخصّان عميلاً آخر (مصانع/الصين) ولم يُستخدما. وكذلك `assets/logo.png` شعار شركة أخرى ولم يُستخدم.
- قصّ الأبراج تم بـ rembg (isnet) مع تنظيف ألوان الحواف وتضييق الألفا قليلاً: لا هالة بيضاء ولا حافة سماء. القصّ على نفس شبكة بكسلات الصورة، فيكمل الأبراج فوق حافة النافذة بلا أي فاصل.
- **الأخضر:** الصور الأصلية فيها غابات خضراء، والهوية تمنع الأخضر. لذلك سُحب نطاق الأخضر في الصور إلى برونزي/شمبانيا دافئ (`prep_malaysia.py`). الماء الفيروزي خُفّف تشبّعه فقط ولم تُغيَّر درجته (حتى لا يمر عبر الأخضر).

## ما الذي نقص
- **لا توجد أيقونات 3D جاهزة** للمميزات السبع ولا للقلبين ولا للطائرة. رُسمت كلها بـ SVG بأسلوب 3D ناعم (لؤلؤي، شمبانيا، جرافيت) بدل استخدام صور لا تناسبها.
- **سيلانجور:** لا توجد صورة خاصة بها. استُخدم تلفريك جنتنج لأن مرتفعات جنتنج تقع على حدود باهانج وسيلانجور، وهو أقرب ما يتوفر. يُفضّل استبداله بصورة من سيلانجور نفسها (مثل كهوف باتو): غيّر `IMG.selangor` في `data.ts`.
- **كوالالمبور:** توجد صورة واحدة فقط، فاستُخدمت للعنوان ولبطاقة المدينة بقصّين مختلفين. صورة ثانية للمدينة ستزيد التنوع.
- **الموسيقى:** لم يتوفر مصدر مرخّص داخل البيئة، فوُلّدت موسيقى سينمائية خفيفة بالكود (pad، أربيجيو، إيقاع يتصاعد، riser، ثم ضربة عند السعر) مع مؤثرات whoosh وtick ولمعة وpop. لا حقوق عليها. الصوت يتلاشى في آخر ثانية، وجهارته الكلية نحو ‎-16.5 LUFS.
- **الخط:** الكود يدعم `@remotion/google-fonts/Cairo` عند ضبط `REMOTION_GOOGLE_FONTS=1`. لكن متصفح الرندر في هذه البيئة لا يصل إلى fonts.gstatic.com (شهادة البروكسي)، فاستُخدمت ملفات Cairo نفسها الموجودة في `assets/fonts`، والنتيجة البصرية مطابقة.

## التوقيتات (من `data.ts`)
| الزمن | الكاميرا | الحدث |
|---|---|---|
| 0–3ث | تبدأ من وسط اللوحة وتصعد بقوس إلى العنوان | الأبراج تطفو، و"ماليزيا" يستقر (ظهور الكلمة كاملة مع blur وانزلاق) |
| 3–6ث | تنزل مع ميل ‎-4° | العدّادان 0→7 و0→6 كبكرات، والقلبان ينبضان |
| 6–9ث | تنزلق عبر المدن | الطائرة تعبر بمسار منحنٍ مع ظل وأثر نقطي، والصور تتحرك بـ parallax |
| 9.3–14ث | سبع محطات، نحو 0.7ث لكل واحدة، بحركة متعرجة RTL | الأيقونة تدور 360° وتلمع عند الوصول |
| 14–16.5ث | توقف ثم اقتراب | بكرات السعر تصل إلى 5,950، ثم لمعة ورذاذ خفيف |
| 16.5–18ث | تراجع حتى تظهر اللوحة كاملة | "احجز الآن" ينبض، ثم تنفصل بطاقات احجز الآن والتواصل والشركة عن اللوحة نحو الكاميرا، ويثبت اسم الشركة |

## فحص الجودة
- الحروف العربية متصلة في كل اللقطات، ولا يوجد letter-spacing ولا تقسيم للحروف. الحركة تشمل الكلمة أو السطر كاملاً.
- RTL صحيح. القيم اللاتينية معزولة LTR، فبقيت علامة "+" في "‎+60126003060" في مكانها.
- المنطقة الآمنة: نصوص المحطات بين y≈300 وy≈1550. العناصر في الشريط العلوي هي قمم الأبراج فقط (ليست نصاً).
  - استثناء معروف: أثناء التوقف على السعر يظهر الحد العلوي لسطر "واتساب" مقطوعاً عند الحافة السفلية (y>1880)، وهو غير مقروء هناك. يظهر كاملاً في المنطقة الآمنة في النهاية.
- حواف القص بلا هالة. لا ارتجاج: الكاميرا دالة ناعمة للزمن، والعدّادات بكرات بعرض ثابت.
- المدة 18.005 ثانية و540 إطاراً. الحجم ~15.6MB، وهو أقل من 30MB.
